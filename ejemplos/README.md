# Ejemplos del curso

Código de referencia en TypeScript para practicar junto al manual.

## Proyecto incluido

| Carpeta | Descripción |
|---------|-------------|
| [`miapp-ts/`](miapp-ts/) | App Create React App + TypeScript con demos enlazadas al temario |

## Uso rápido

```bash
cd ejemplos/miapp-ts
npm install
npm start
```

Abre [http://localhost:3000](http://localhost:3000) y elige un ejemplo en el menú lateral.

Los laboratorios del manual se hacen en **proyectos nuevos** (Vite o la plantilla del lab 8.1). Esta app sirve para ver código funcionando mientras lees los capítulos.
